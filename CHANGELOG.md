## [0.1.0] - 2026-11-13

### Added

- Natural Generation — Describe any process or structure in plain English and receive valid Mermaid syntax instantly via Ollama.
- Notebook UI — Handwriting-font headings, lined paper background, wobbly borders and highlighter accents create a familiar sketchbook feel.
- AI Refinement — Iterate by telling the model to add steps, change layout or clarify elements without rewriting prompts.
- Live Preview — Real-time Mermaid renderer updates as you edit the generated code with instant visual feedback.
- One-click Export — Export diagrams as SVG, PNG, PDF or copy Markdown embed code with a single button.
- Template Gallery — Start from common patterns such as system architecture, user flows, sequence diagrams and org charts.
- Explanation Mode — Ask the LLM to describe a diagram back in plain English or suggest improvements.
- CLI Companion — Generate diagrams directly from terminal with `diatype generate` for use in scripts and CI.
